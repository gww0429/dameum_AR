인식 파일 만들기

벽면 그래픽 이미지를 AR 인식 파일(targets.mind)로 변환합니다. 그래픽을 바꿀 때마다 한 번씩 실행하세요.

2. 변환

3. 교체 방법

  1. 내려받은 targets.mind를 assets 폴더에 덮어씁니다.
  2. 그래픽 이미지도 assets 폴더에 넣습니다 (스캔 안내 화면에 쓰임).
  3. 3D 모델(.glb)을 assets 폴더에 넣습니다.
  4. config.js의 targets에 이미지·모델 경로를 적습니다. 순서는 위에서 선택한 순서와 같아야 합니다.
  5. 모델 크기·위치는 scale, position 값으로 조정합니다.
